## 3. 설치 및 사용
### HTML 판 (권장)
설치 없음. `장비관리대장_생성기.html` 을 Chrome/Edge 로 연다.
1. **엑셀**: 통합본을 끌어다 놓거나 클릭. 장비 시트(기본: 장비대장·기타장비)를 칩으로 켜고 끔. 장비구성 시트 자동 선택.
1-1. 시트는 장비대장·기타장비·이관장비가 기본 선택되며 이 순서로 만들어짐. 이관장비에 있는 장비는 장비대장에서 자동 제외(기록에 표시).
2. **사진 폴더**: 폴더를 끌어다 놓거나 클릭. 파일명 = 관리번호(`04-장비-05.jpg`, `04-장비-기타1.jpg`). HEIC 등은 JPG 로, 1MB 이상은 300KB 이하로.
3. **옵션**: Word 하나로/장비별 ZIP, 날짜 표기, 카탈로그 함께 만들기(기본 켬), 카탈로그 사진 크기.
4. **대상 확인**: ‘성능 글자’ 열 — `10pt`(그대로) / `8.5pt 축소` / `넘침 위험`.
5. **실행**: Word + 카탈로그가 내려받아짐. 실행 기록에 글자를 줄인 장비가 표시됨.

### 관리대장(HTML)에서 편집하기 (v2.1)
1. **직인 관리**(상단 버튼): 담당자·팀장을 등록하고 직인/사인 그림을 올리거나 [서명 그리기]. 흰 배경은 자동으로 지움.
   - 사람이 바뀌면 **새 사람을 등록**(사용 시작일 입력). 지난 이력은 원래 사람 직인 그대로, 새 이력은 '현재' 사람이 기본값.
2. 장비 카드 → 상세 → **장비구성내역 [✎ 편집]**: 행 추가·삭제·순서 바꾸기 → [저장].
3. 상세 → **수리 또는 부품 교체 이력 [+ 이력 추가]**: 일자·내용·담당자·팀장 → [저장]. Word 뒷면에 직인과 함께 들어감(22건 넘으면 뒷면 1쪽 추가).
4. 고친 내용은 이 브라우저에 **임시 저장**되고 아래쪽 검은 띠에 건수가 보임. 확정하려면:
   - **통합 엑셀 내보내기** → `날짜_장비관리대장 통합.xlsx` (장비구성·수리이력·직인관리 시트 갱신, 나머지 시트는 그대로). **다음에 생성기를 돌릴 때 이 파일을 쓰세요.**
   - **관리대장 파일 저장** → 고친 내용이 들어간 새 HTML (다른 사람에게 보낼 때).
5. 같은 관리번호 장비(예: 구입일련번호만 다른 2대)는 구성·이력을 함께 씁니다.

### 카탈로그 사용
- 검색바: 관리번호 / 물품명 / 통합검색(쉼표로 여러 개, 일부만 입력해도 됨). `/` 키로 검색창 이동.
- 금액 칩: 100만 미만 ~ 1억 이상(괄호 숫자 = 장비 수). **상세 검색**: 금액 분포 막대 + 슬라이더 + 만원 단위 직접 입력, 단가/총액, 도입연도, 제조국, 구분, 사진·구성 있는 장비만.
- 카드 클릭 → 상세(큰 사진, 기본 정보, 도입처, 주요 성능, 장비구성내역 표 — 없으면 빈 표와 안내). ←/→ 이동, 사진 클릭 → 크게.
- 상세 오른쪽: **Word 장비관리대장 내려받기**(그 장비 1대), **엑셀 원본에서 이 행 보기**, 인쇄.
- **엑셀 원본 보기** 탭: 원본 엑셀의 모든 시트를 표로, 찾기·줄바꿈, 관리번호 클릭 → 상세.
- **보내기**: 원본 엑셀 공유(지원 브라우저)·메일로 보내기·원본 내려받기·보이는 장비 엑셀/Word·목록 인쇄.
- ♡ 관심 장비: 이 브라우저에만 저장.

### Python 판
```bash
pip install -r requirements.txt          # openpyxl, lxml, pillow, pillow-heif
python 장비관리대장_생성기.py              # 창
python 장비관리대장_생성기.py --xlsx 통합.xlsx --images 사진폴더 [--zip] [--only 04-장비-05] [--catalog-only]
```

## 4. 배포 방법
- **사용자에게**: `장비관리대장_생성기.html` 1개(약 2.8MB) — 메일·공유폴더·USB. 인터넷 불필요.
- **결과 공유**: `장비카탈로그_날짜.html` 1개 — 사진·원본 엑셀·양식이 들어 있어 받은 사람도 검색·Word 생성 가능(약 4~5MB).
- **수정 후 재배포**: 부품 파일 수정 → `python build.py` → `dist/` 의 HTML 배포. 부품 위치는 `부품설계도.md` §6.

## 5. 주의
- Word 쪽 맞춤은 LibreOffice 로 검증했다. Word 실물에서 처음 한 번 몇 장 확인 권장.
- 1MB 미만 사진은 원본 그대로 넣으므로 전체 Word 가 약 30MB 가 된다(48대). 줄이려면 ‘사진 줄이기 기준’을 낮춘다(예: 300KB).
- 직인 그림은 엑셀 '직인관리' 시트에 글자로 저장됩니다(그림 1개 약 1~2만 자). 이 칸을 직접 고치지 마세요.
- 관리대장(HTML)의 임시 저장은 그 PC·그 브라우저에만 남습니다. 꼭 [통합 엑셀 내보내기]로 확정하세요.
- 카탈로그 디자인은 airbnb DESIGN.md 를 참고만 했으며 로고·상표는 쓰지 않았다. 대외 공식 배포물에는 기관 색으로 바꾸는 것을 권장(`catalog.css` 의 --primary).
