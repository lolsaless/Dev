# 한강권역 물환경 수질측정망 대시보드 매뉴얼 (v4.0)

> 물환경 **수질측정망 API 자료**(대권역 한강, 2000년~)를 **조사기관별로 묶어** 보는 HTML 대시보드.
> 측정값은 모두 API에서 받은 것이다. v3까지의 연구원 자체 조사 엑셀 DB는 v4에서 뺐다.

| 하고 싶은 일 | 실행할 것 |
|---|---|
| 대시보드 보기 | `한강권역_수질측정망_대시보드.html` 더블클릭 (설정 저장·V월드 지도는 `대시보드_열기_windows.bat` / `_mac.command`) |
| 최신 자료 받기(API) → HTML 다시 만들기 | `수질측정망_갱신_windows.bat` / `수질측정망_갱신_mac.command` |
| 매달 자동 갱신 예약 | `도구모음` → 8번 (또는 `python tools/make_launchers.py --schedule`) |
| 프로그램을 고친 뒤 HTML 다시 만들기 | `빌드_windows.bat` / `빌드_mac.command` |
| 실행 파일(.bat·.command)이 지워지거나 깨졌을 때 | `python tools/make_launchers.py` |
| 어느 부품을 고칠지 찾기 | `문서/부품지도.md` (빌드할 때 자동 생성) |

---

## 1. 최초 기획

### 1.1 배경
- v3까지는 연구원이 직접 조사한 37개 시료번호(2026년, 엑셀 DB)만 볼 수 있었다.
- 같은 수계의 국가 수질측정망 자료(2000년~)와 기관별 지점을 함께 보고, 오래된 경향까지 해석하고 싶다는 요구가 생겼다.

### 1.2 v4 요구사항과 반영 결과
| 요구 | 반영 |
|---|---|
| 연구원 자체 DB 제거 | 측정결과·지점정보·연평균색도 시트와 관련 기능(월별 가져오기, 지점 관리, 좌표 일괄 검색)을 뺐다. 엑셀은 **설정 전용(`수질측정망_설정.xlsx`)** 으로 남겼다 |
| API 자료를 **조사기관별로** 묶어 보기 | 관리 구분 버튼 = 조사기관 12곳 |
| 순서: 경기도 보건환경연구원 맨 위, 나머지는 **지점이 많은 순** | 경기도 보건환경연구원 68 → 한국농어촌공사 176 → 한강유역환경청 149 → 원주지방환경청 83 → 한강물환경연구소 81 → 한국수자원공사 26 → 서울특별시 보건환경연구원 23 → 강원도 보건환경연구원 18 → 충청북도 보건환경연구원 16 → 인천광역시 보건환경연구원 4 → 충청남도 보건환경연구원 2 → 금강유역환경청 1 |
| 7개 항목만 | TOC·COD·BOD·SS·T-N·T-P·색도 |
| 기간 설정, `19년 9월` 표기, 비슷한 경향 지점, 자료 해석 | v3.2 기능 그대로 유지 |

## 2. 개발 과정

### 2.1 자료 흐름
```
공공데이터포털 API ─(tools/api_update.py)→ 수질측정망/연도별/YYYY.csv → 수질측정망_자료.csv
                                                                   │
수질측정망_설정.xlsx(항목·기준값·설정) ─┐                               │
                                    ├─(tools/data_builder.py + api_data.py)→ 데이터(D)
소스/ 부품 53개 ────────────────────┴─(tools/build.py)→ 한강권역_수질측정망_대시보드.html
```
- `api_data.py`: 같은 달 여러 회차는 **평균**, 월은 API 측정연월(wmyr·wmod) 기준. 지점 647개 × 321개월 × 7항목 표를 **한 번만** 넣고(값은 '시작 위치|값,값,,값' 글자로 줄여 저장), 화면이 열릴 때 고른 기관 지점만 풀어 쓴다.
- 자동 점검: 이상값 의심(지점 중앙값 대비 로버스트 z ≥ 6 이고 5배 이상 차이), 전월 동일(4개 항목 이상 값이 같음), 검사일이 측정연월과 2개월 이상 어긋남.

## 3. 설치 및 사용

### 3.1 설치(최초 1회)
1. Python 3을 설치한다(Windows는 설치 화면에서 "Add python.exe to PATH" 체크). API 갱신은 추가 패키지가 필요 없고, 빌드는 `openpyxl`을 처음 실행 때 자동 설치한다.
2. `수질측정망/물환경.env` 에 공공데이터포털 인증키가 있는지 확인한다(`DATA_GO_KR_API_KEY=키값`).
3. Mac은 `.command` 파일을 처음 열 때 오른쪽 클릭 → 열기.

### 3.3 화면 구성
| 위치·탭 | 내용 |
|---|---|
| 시계열 탭 앞 **관리 구분** | 현재 관리 구분을 누르면 **전체 지점**과 조사기관 목록이 열림(경기도 보건환경연구원 → 지점 많은 순). 다른 기관을 눌러도 **보던 탭·항목·기간이 그대로** 이어진다(예: 지도·TOC·최근 5년). 처음 열면 경기도 보건환경연구원, 한탄강 중권역 지점 · 최근 10년 |
| 왼쪽 목록 | 중권역(하천) 묶음은 **기본으로 접혀 있다.** 이름 왼쪽 **▸** 를 누르면 지점이 펼쳐지고 ▾ 로 접는다(펼친 상태는 기억). 이름 옆 `3/16` = 선택 3개 / 지점 16개. 검색하면 맞는 하천이 펼쳐진다. 전체 지점 묶음에서는 지점 옆에 조사기관이 나온다 |
| 분석항목 옆 아이콘 | 슬라이더는 **표시 옵션**, 팔레트는 **색상 설정**(3.7). 관리 구분 메뉴에서 자료 범위·갱신 시점·집계 기준을 확인 |
| 위쪽 **기간 설정** | 시작·끝 연/월, 최근 1·3·5·10년·올해·작년·전체 |
| 시계열 | 꺾은선(`19년 9월` 표기) + **비슷한 경향 지점 찾기** + 데이터 표 |
| 지도 | 원 색 = 농도(**옅은 파랑 낮음 → 빨강 높음**), 원 크기 = 농도(높을수록 큼). 색 범위는 최솟값 ~ 상위 95% 값 |
| 히트맵 | 지점별 측정연월 히트맵. 셀 또는 지점명을 누르면 아래에 그 지점의 **연도 × 1~12월 히트맵**(위 히트맵과 같은 칸 높이·같은 색 눈금, **최근 연도가 맨 위**, 값이 있는 해만, 회색 칸 = 미측정, [표 복사]). 기간이 길어 칸이 좁으면 칸 안 숫자는 숨기고 마우스를 올리면 보인다 |
| 상·하류 종단 | 점 색·크기 = 농도. **구간별 변화 표**는 고른 중권역(예: 한탄강)의 **모든 지류 지점**을 한 표에 보여 준다(흐름 그룹 순서, `비교 상류` = 같은 흐름의 바로 위 지점, 여러 흐름이 만나는 지점은 `합류` 표시). 표 오른쪽 위 **[자동·연평균·월별]**: 자동은 기간 24개월 이하면 월별, 넘으면 연평균(10년이면 11열). **[✎ 종단 편집]**: 지도에서 중권역을 고르고 흐름 그룹별 순서와 합류를 정한다(3.6) |
| 연도별 색도·경향 분석 | 경향 분석은 추세 검정·항목 간 상관·월별 분포·기준 초과율·최근 12개월 비교(계절 기준 이탈은 v4.1에서 뺌). **추세 검정**은 그래프 바로 위 막대에서 시료번호(목록·◀▶)와 항목 버튼으로 바꾼다. 키보드 ← → = 시료번호, ↑ ↓ = 항목. 항목 버튼 밑줄 색 = 그 지점의 추세(빨강 증가·파랑 감소, 진할수록 유의) |
| 자료 해석 | 수준·추세·최근 변화·계절·지점 구분·항목 관계를 문장으로, 표 복사·MD 저장. 계절 막대 색은 그래프 오른쪽 위 **막대 색(강우기·갈수기·기타)** 에서 바꾸고 [기본색]으로 되돌림 |
| 자료 점검 | 이상값 의심·전월 동일·검사일 불일치 |
| 설정 | V월드 키·화면 기본값·점검 기준 (서버로 열면 `수질측정망_설정.xlsx`에 저장) |

- 기관마다 재는 항목이 다르다(예: 경기도 보건환경연구원 지점은 색도가 거의 없음). 그래프 제목 옆에 "⚠ 이 항목 자료가 없습니다"가 나오면 다른 항목을 고른다. 기본 항목은 TOC.
- 비슷한 경향 지점 찾기: 관리 구분 전체 또는 선택한 지점을 대상으로 **[비교 실행]** 을 누른다. 같은 달 측정값이 12개월 이상 겹치는 모든 지점 쌍의 Spearman ρ를 계산한다. 각 묶음의 모든 내부 쌍이 기준을 충족한다. 묶음을 펼쳐 **[이 지점만 보기]**, **[이전 선택으로]** 를 이용한다. 계절 제거는 지점별 같은 달의 평균을 뺀 값으로 비교한다.

### 3.6 상·하류 종단 편집
1. 상·하류 종단 탭의 **[✎ 종단 편집]** 에서 중권역을 고른다.
2. 지류나 본류를 **흐름 그룹**으로 만들고 이름을 붙인다. 그룹마다 **[지도에서 순서 다시 지정]** 을 눌러 상류부터 지점을 고른다. 목록의 ▲▼로 순서를 조정할 수 있다.
3. **하류에서 만나는 그룹**을 지정하면 선택한 그룹의 마지막 지점이 하류 그룹에도 있으면 그 지점에서 합류한다. 공유 지점이 없으면 하류 그룹 첫 지점으로 이어진다. 합류하는 경로는 기본으로 하나의 농도 그래프에 함께 표시하며, 공유 지점에서 동일한 농도로 만난다. 두 지류가 같은 곳에서 만나면 두 그룹에 동일한 하류 그룹을 지정한다.
4. **[저장]** 하면 구간별 변화 표에 모든 흐름의 지점이 함께 나온다(흐름을 따로 고르지 않음). 서버로 열면 설정 파일의 **종단순서** 시트에, HTML을 직접 열면 이 브라우저에 저장된다. **[기본 순서로]** 는 해당 관리 구분·중권역의 종단을 지점코드 순서로 되돌린다.

### 3.7 그래프 색상 설정
분석항목 옆 **팔레트 아이콘**을 누른다. 색 칸을 누르면 바로 모든 그래프에 반영되고 이 브라우저에 저장된다. 직접 바꾼 색 옆 **↺** 는 그 색만 기본값으로, **[색상 초기화]** 는 전부 기본값으로 되돌린다.

| 묶음 | 바뀌는 곳 |
|---|---|
| 그래프 선 | 주 선(추세 검정 그래프·종단 강조 월·자료 해석 연평균), 비교 선(최근 12개월 비교의 직전 12개월), 기준선(생활환경기준 등급), 목표선 |
| 판정·강조 | ▲ 평균보다 높음, ▼ 낮음, 기본 선(지점이 많을 때 강조 안 한 지점), ⚡ 특이 경향 선 |
| 시료번호 색 1~16 | 시계열·산점도 등에서 지점에 자동 배정되는 순서의 색. 지점 하나만 바꾸려면 왼쪽 목록의 ● 를 누른다 |
| 농도 색 5단계 | 지도·히트맵·종단 점의 낮음→높음 색. **미리 정한 조합**: 기본(파랑→빨강)·초록→빨강·한 색(파랑 진하기)·색약 배려(파랑→주황)·회색조(흑백 인쇄) |

- 직접 고른 색은 라이트·다크 모드 모두에 쓰인다. 자료 해석의 계절 막대 색은 그 화면 오른쪽 위에서 따로 바꾼다.

### 월별 수질 경향과 자료 점검
- 히트맵 기본 화면에는 선택 기간의 지점별 월 대표값이 표시된다. 셀을 누르면 해당 지점의 보유 기간 전체를 연도별로 표시한다. 회색은 미측정이다.
- **최근 12개월 비교**는 선택 기간의 마지막 12개월과 직전 12개월을 같은 달끼리 비교한다.
- 자료 점검의 **보기**는 해당 관측을 시계열 상단과 그래프에 표시한다. **표에서 값 보기**를 누르면 해당 관측 셀로 이동한다.

### 3.4 매달 하는 일
1. 인터넷이 되는 PC에서 `수질측정망_갱신` 실행(또는 예약이 자동 실행) → 올해·작년·빠진 연도만 다시 받고 HTML을 다시 만든다.
2. **자료 점검** 탭에서 새 이상값을 확인한다(값은 고치지 않고 원자료 문의).
3. 행정망 PC에는 만든 HTML만 옮긴다(행정망은 API 접속 불가).

### 3.5 API 갱신 명령
| 명령 | 하는 일 |
|---|---|
| `python tools/api_update.py` | 자동: 빠진 연도 + 최근 2개 연도 + 실패 연도 |
| `--years 2024 2025` | 지정 연도 |
| `--full` | 2000년~올해 전부(오래 걸림) |
| `--check-key` | 인증키 1건 시험 |
| `--merge-only` | 받지 않고 합치기만 |
| `--import-local "폴더"` | 이미 받은 원본 연도별 CSV(전체 열)에서 7개 항목만 가져오기 |

- 일부 묶음이 실패한 연도는 `연도_partial.csv`로 따로 두고 완성본은 건드리지 않는다. 인터넷이 없으면 10초 안에 멈춘다.

## 6. 문제 해결
| 증상 | 원인·조치 |
|---|---|
| 빌드 오류 "수질측정망 자료가 없습니다" | `수질측정망_갱신` 또는 `--import-local` 로 자료를 먼저 만든다 |
| 갱신 시 "공공데이터포털에 연결할 수 없습니다" | 인터넷이 안 되는 PC(행정망)다 |
| "인증키 오류" | `수질측정망/물환경.env` 확인(발급 직후 1시간쯤은 안 될 수 있음) |
| 그래프가 비어 있음 | 그 기관이 그 항목을 재지 않거나 기간에 자료가 없다. 항목·기간을 바꾼다 |
| HTML이 열리는 데 몇 초 걸림 | 자료가 647개 지점·27년이라 정상(약 7MB) |
| 설정 탭에 "파일로 열림" | 저장하려면 `대시보드_열기`로 연다 |
| 예약이 안 돎(Mac) | 시스템 설정 > 개인정보 보호 > 파일 및 폴더 접근 허용, `수질측정망/예약실행_출력.txt` 확인 |

## 7. 주의
1. `한강권역_수질측정망_대시보드.html`은 직접 고치지 않는다(빌드 때 덮어씀). `소스/` 부품을 고친다.
2. 원인 설명(자료 해석 탭)은 일반 수질 지식에 따른 **가능성**이다. 보고서에는 유량·강우·오염원 자료로 확인 후 쓴다.
3. API 원자료에 검사일이 측정연월과 크게 다른 행(예: 2909-12-10)이 있다. 값은 측정연월 기준으로 쓰고 '검토필요'로 표시만 한다.
4. 2016년 전후로 측정 횟수가 바뀐 지점이 많다(월 1회 → 2~4회). 월 평균값을 쓰므로 오래된 자료와 비교할 때 주의.
5. 한국농어촌공사 지점(176개)은 대부분 농업용수 저수지(호소)다. 하천과 같은 기준으로 비교하지 않는다.
6. **미검증**: 실제 API 호출, Windows `.bat`, 자동 갱신 예약 — 처음 쓸 때 `도구모음 7번(키 시험) → 6번(갱신)` 순서로 확인한다.
