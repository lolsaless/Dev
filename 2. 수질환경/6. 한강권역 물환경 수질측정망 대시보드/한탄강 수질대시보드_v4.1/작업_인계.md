## 빌드와 확인

1. 기준본 폴더에서 `python3 tools/build.py --cache`, `python3 tools/build.py --cache --no-key`를 차례로 실행한다. 내장 측정값을 다시 읽거나 갱신할 필요가 없을 때 캐시 빌드를 사용한다.
2. 새 회귀 시험은 `python 시험/합류_히트맵_분석_시험.py 한강권역_수질측정망_대시보드_공유용.html`. Playwright와 macOS Google Chrome이 필요하다. 실제 캔버스 좌표 클릭, 지점 변경 전후 제목·데이터, 계절 이탈 짧은 기간, 차탄천 합류 좌표를 검사한다. 서버 저장은 작업 폴더 전체의 임시 복사본에서 실행했다.
3. 기존 시험은 `python3 시험/빌드_시험.py` 및 `python 시험/화면_시험.py HTML절대경로 결과폴더`. 기존 화면 시험은 Playwright 기본 Chromium을 사용한다. 이 Mac에서는 설치된 Chrome 채널로 실행해 확인했다.
4. 직접 열린 HTML과 로컬 서버가 사용하는 종단 저장소가 다르다. HTML은 브라우저 저장소를 쓰며, Mac·Windows 실행 도구를 통한 서버 모드는 설정 엑셀의 종단순서 시트를 쓴다. 직전판에서 저장되지 않은 편집은 새 파일로 가져올 수 없다.

## 후속 작업 시 주의

- 새 파일에 사용자 작업본을 덮어쓰지 않는다. 변경할 때 소스 부품부터 수정하고 실행용 두 HTML을 다시 빌드한다.
- 첨부 사례는 검증용 경로다. 전달본 설정 엑셀에 예시를 사전 등록하지 않았다.
- 차탄천의 동일한 관측값에서 선이 만나는 것은 지류별 농도를 합산하거나 유량 가중 혼합을 추정하는 계산이 아니다. 측정점 사이 거리는 표시 간격에 반영하지 않는다.
- 이번 검증은 Chrome에서 수행했다. Windows 실기기, Safari 및 V월드 실시간 타일 연결은 별도 확인 항목이다.
